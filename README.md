# Araz Terrace

Luxury multilingual restaurant website (AZ / TR) — Next.js 15.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000/az

## Deploy on Vercel

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import GitHub repo: `lamforwardx-commits/Aliservis.az`
3. Framework Preset: **Next.js** (auto-detected)
4. Root Directory: leave as **`.`** (repo root)
5. Click **Deploy**

If an old project was connected with Root Directory = empty/wrong folder, open  
**Project → Settings → General → Root Directory** and clear it (or set to `.`), then **Redeploy**.
